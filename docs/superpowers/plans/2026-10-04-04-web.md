# Máy chủ và giao diện web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây bản demo web chạy được: bản đồ Goong có lớp nguy cơ ngập, tìm đường tránh ngập, báo ngập một chạm có đếm số người báo, và cảnh báo sớm cho vị trí đã lưu.

**Tech Stack:** Python 3.12, FastAPI, Uvicorn, httpx, SQLite, GeoPandas, Shapely; React, Vite, TypeScript, Tailwind CSS, MapLibre GL JS, vitest; Docker.

### F. Tìm đường (Task 5)

Quy tắc ở QĐKT mục 7.2.

- **Bỏ `detour_points` và mọi kiểm thử của nó.** Việc tìm đường tránh do `graphroute.py` làm (xem dưới).
- Thêm `POST /api/score-route` nhận `{city, coordinates, vehicle}`, trả kết quả của `score_route`. Trả 422 khi có dưới hai điểm hoặc điểm nằm ngoài khung thành phố.
- **Kiểm thử phải sửa:** dữ liệu mẫu có `loc_weight` 1 ở đoạn số chẵn và 0,3 ở đoạn số lẻ, nên lộ trình dọc "Dọc 4" (đoạn 7) có `flooded_m` khoảng 0,3 lần chiều dài. Thêm kiểm thử: ô tô trên đoạn có `max_depth_cm` 25 nhận nửa điểm.

**Thuật toán tìm đường riêng (`api/graphroute.py`).** Quy tắc, tốc độ theo loại đường và mức phạt ở QĐKT mục 7.2. Mạng đường đọc từ `graph_nodes.parquet`, `graph_edges.parquet`, `edge_units.parquet`; dữ liệu mẫu của kế hoạch 01 có sẵn một lưới 4 × 4 giao lộ để viết và kiểm thử.

```python
class RoadGraph:
    """Nạp ba bảng một lần khi máy chủ khởi động; mỗi thành phố một đối tượng."""

    def __init__(self, nodes, edges, edge_units): ...
    def nearest_node(self, lon: float, lat: float) -> int: ...          # chỉ số của nút gần nhất
    def base_time(self, vehicle: str) -> np.ndarray: ...                 # giây cho từng cạnh; inf ở cạnh xe đó không được đi
    def penalized(self, vehicle: str, risk_view, scores) -> np.ndarray: ...   # thời gian cộng phần phạt cho từng cạnh
    def shortest(self, src: int, dst: int, cost: np.ndarray) -> list[int] | None: ...   # danh sách edge_id; None nếu không tới được
    def describe(self, edge_ids: list[int], vehicle: str) -> dict: ...   # coords, distance_m, duration_s (không tính phần phạt)
```

Phần lõi của `shortest`, để tham khảo (chưa chạy):

```python
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import dijkstra


def shortest(self, src: int, dst: int, cost: np.ndarray) -> list[int] | None:
    usable = np.isfinite(cost)
    matrix = csr_matrix((cost[usable], (self.u[usable], self.v[usable])), shape=(self.n, self.n))
    dist, pred = dijkstra(matrix, directed=True, indices=src, return_predecessors=True)
    if not np.isfinite(dist[dst]):
        return None
    path, node = [], dst
    while node != src:
        prev = int(pred[node])
        path.append(self.edge_of[(prev, node)])
        node = prev
    return path[::-1]
```

Trong đó `self.u`, `self.v` là chỉ số nút (0 tới `n − 1`) của từng cạnh, và `self.edge_of` là từ điển từ cặp chỉ số nút sang số thứ tự cạnh. Mỗi cặp nút chỉ có một cạnh (người dữ liệu đã lọc cạnh song song), vì `csr_matrix` cộng dồn các phần tử trùng vị trí.

`penalized`: với mỗi dòng của `edge_units`, phần phạt bằng `length_m / tốc độ × loc_weight × hệ số xe × mức phạt`, với mức phạt 2 cho mức vừa và 20 cho mức cao; cộng dồn theo cạnh bằng `np.bincount` rồi cộng vào `base_time`.

`GET /api/route` làm bốn bước:

1. Gọi Goong với `alternatives=true`, chấm điểm từng lộ trình bằng `score_route`.
2. Gắn điểm đi và điểm đến vào nút gần nhất; chạy `shortest` hai lần, với `base_time` và với `penalized`.
3. Chấm điểm đường tránh bằng `score_route` trên tọa độ của nó.
4. Chọn lộ trình đề xuất theo QĐKT mục 7.2. Mỗi lộ trình trả thêm `engine` (`"goong"` hoặc `"own"`) và `estimated` (đúng với lộ trình của thuật toán riêng).

Khi Goong lỗi, vẫn trả đường của thuật toán riêng, kèm một dòng ghi chú. Khi thuật toán riêng không tìm được đường, chỉ trả lộ trình của Goong.

Kiểm thử trên lưới mẫu:
- Mọi đoạn mức thấp: đường tránh trùng với đường nhanh nhất.
- Đi từ đầu tới cuối "Ngang 4" (đoạn mẫu số 6, mức cao, `loc_weight` bằng 1): đường tránh không dùng cạnh nào của đoạn đó, và dài hơn đường thẳng.
- Đường tránh không bao giờ có chi phí có phạt lớn hơn đường nhanh nhất.
- Cạnh `motorway` có `base_time` vô hạn với xe máy và hữu hạn với ô tô.
- Hai điểm không nối được với nhau: `shortest` trả `None` và endpoint chỉ trả lộ trình của Goong.
- Goong lỗi: endpoint vẫn trả đường của thuật toán riêng với mã 200.

Kiểm tra bộ nhớ và tốc độ trên mạng đường thật của TP.HCM ngay khi có file: một lần `shortest` phải dưới 0,5 giây. Nếu chậm hơn, giới hạn đồ thị trong khung chữ nhật quanh hai điểm, nới 3 km mỗi phía.

```python
from __future__ import annotations

import json
from dataclasses import dataclass

import geopandas as gpd
import numpy as np
import pandas as pd
from pyproj import Transformer
from shapely.geometry import Point, box

from floodrisk.config import CITIES, TZ, risk_path, thresholds_path, units_path

DEFAULT_THRESHOLDS = {"medium": 0.35, "high": 0.60}
STALE_AFTER = pd.Timedelta(hours=3)


def _empty_risk() -> pd.DataFrame:
    return pd.DataFrame({
        "unit_id": pd.Series(dtype="object"), "hour_offset": pd.Series(dtype="int64"),
        "risk": pd.Series(dtype="float64"), "level": pd.Series(dtype="int64"),
    })


@dataclass
class CityData:
    city: str
    units: gpd.GeoDataFrame  # unit_id, name, geometry (EPSG:4326, đã đơn giản hóa), chỉ số 0..n-1
    proj: gpd.GeoSeries  # hình học gốc trong hệ mét, cùng chỉ số
    names: pd.Series  # unit_id -> name
    to_proj: Transformer
    to_wgs: Transformer
    risk: pd.DataFrame
    risk_mtime: float = -1.0
    computed_at: pd.Timestamp | None = None


class Store:
    def __init__(self) -> None:
        self._cities: dict[str, CityData] = {}

    def available(self) -> list[str]:
        return [city for city in CITIES if units_path(city).exists()]

    def thresholds(self) -> dict:
        path = thresholds_path()
        return json.loads(path.read_text(encoding="utf-8")) if path.exists() else dict(DEFAULT_THRESHOLDS)

    def get(self, city: str) -> CityData:
        if city not in CITIES:
            raise KeyError(city)
        if city not in self._cities:
            if not units_path(city).exists():
                raise FileNotFoundError(units_path(city))
            self._cities[city] = self._load(city)
        cd = self._cities[city]
        self._refresh(cd)
        return cd

    def _load(self, city: str) -> CityData:
        full = gpd.read_parquet(units_path(city)).reset_index(drop=True)
        crs = full.estimate_utm_crs()
        units = full[["unit_id", "name", "geometry"]].copy()
        units["geometry"] = units.geometry.simplify(0.00003)
        return CityData(
            city=city, units=units, proj=full.geometry.to_crs(crs),
            names=full.set_index("unit_id")["name"],
            to_proj=Transformer.from_crs(4326, crs, always_xy=True),
            to_wgs=Transformer.from_crs(crs, 4326, always_xy=True),
            risk=_empty_risk(),
        )

    def _refresh(self, cd: CityData) -> None:
        path = risk_path(cd.city)
        if not path.exists():
            return
        mtime = path.stat().st_mtime
        if mtime == cd.risk_mtime:
            return
        risk = pd.read_parquet(path)
        cd.risk, cd.risk_mtime = risk, mtime
        cd.computed_at = pd.Timestamp(risk["computed_at"].iloc[0]) if "computed_at" in risk.columns and len(risk) else None

    def stale(self, cd: CityData) -> bool:
        now_local = pd.Timestamp.now(tz=TZ).tz_localize(None)
        return cd.computed_at is None or now_local - cd.computed_at > STALE_AFTER

    def in_bbox(self, cd: CityData, west: float, south: float, east: float, north: float) -> np.ndarray:
        return cd.units.sindex.query(box(west, south, east, north))

    def nearest(self, cd: CityData, lon: float, lat: float, max_m: float) -> int | None:
        x, y = cd.to_proj.transform(lon, lat)
        hit = cd.proj.sindex.nearest(Point(x, y), max_distance=max_m, return_all=False)
        return int(hit[1][0]) if hit.shape[1] else None

    def within(self, cd: CityData, lon: float, lat: float, radius_m: float) -> np.ndarray:
        x, y = cd.to_proj.transform(lon, lat)
        return cd.proj.sindex.query(Point(x, y).buffer(radius_m), predicate="intersects")
```

```python
from __future__ import annotations

from datetime import datetime

import numpy as np
import pandas as pd

from floodrisk.api.store import CityData


def view(cd: CityData, hour: int, active: dict, thresholds: dict, now: datetime) -> pd.DataFrame:
    """Nguy cơ của mọi tuyến tại một mốc giờ; `active` là báo cáo còn hiệu lực theo unit_id."""
    base = cd.risk[cd.risk["hour_offset"] == hour].drop_duplicates("unit_id").set_index("unit_id")[["risk", "level"]]
    df = pd.DataFrame(index=pd.Index(cd.units["unit_id"], name="unit_id")).join(base)
    df["risk"] = df["risk"].fillna(0.0).astype(float)
    df["level"] = df["level"].fillna(0).astype(int)
    df["source"] = "model"
    df["reporters"] = 0
    df["reported_level"] = pd.Series([None] * len(df), index=df.index, dtype=object)
    if hour != 0 or not active:
        return df

    from floodrisk.model.combine import to_level
    from floodrisk.model.evidence import apply_evidence

    for unit_id, reports in active.items():
        if unit_id not in df.index:
            continue
        result = apply_evidence(float(df.at[unit_id, "risk"]), reports, now)
        level = int(to_level(np.array([result.risk]), thresholds)[0])
        if result.reported_level == 2:
            level = max(level, 1)
        elif result.reported_level == 3:
            level = 2
        df.at[unit_id, "risk"] = result.risk
        df.at[unit_id, "level"] = level
        df.at[unit_id, "source"] = "official" if any(r.official for r in reports) else "report"
        df.at[unit_id, "reporters"] = result.reporters
        df.at[unit_id, "reported_level"] = result.reported_level
    return df
```

```python
from __future__ import annotations

from fastapi import FastAPI, HTTPException, Query
from shapely.geometry import mapping

from floodrisk.api.context import Context
from floodrisk.config import CITIES

MAX_FEATURES = 3000


def parse_bbox(text: str) -> tuple[float, float, float, float]:
    try:
        west, south, east, north = (float(v) for v in text.split(","))
    except ValueError:
        raise HTTPException(422, "bbox phải có dạng w,s,e,n gồm bốn số")
    if not (west < east and south < north):
        raise HTTPException(422, "bbox phải có w < e và s < n")
    return west, south, east, north


def register(app: FastAPI, ctx: Context) -> None:
    @app.get("/api/health")
    def health():
        return {"ok": True}

    @app.get("/api/cities")
    def cities():
        return [
            {"key": c.key, "name": c.name, "center": list(c.center), "bbox": list(c.bbox),
             "validated": c.validated, "has_tide": c.has_tide}
            for c in (CITIES[key] for key in ctx.store.available())
        ]

    @app.get("/api/risk")
    def risk(city: str, bbox: str, hour: int = Query(0, ge=0, le=2), min_level: int = Query(1, ge=0, le=2)):
        cd = ctx.city(city)
        west, south, east, north = parse_bbox(bbox)
        sub = cd.units.iloc[ctx.store.in_bbox(cd, west, south, east, north)]
        table = ctx.view(cd, hour).loc[sub["unit_id"]]
        keep = ((table["level"] >= min_level) | (table["reporters"] > 0)).to_numpy()
        features = [
            {
                "type": "Feature",
                "geometry": mapping(geom),
                "properties": {
                    "unit_id": unit_id, "name": name, "level": int(row.level), "risk": round(float(row.risk), 3),
                    "source": row.source, "reporters": int(row.reporters),
                    "reported_level": None if row.reported_level is None else int(row.reported_level),
                },
            }
            for unit_id, name, geom, row in zip(sub["unit_id"][keep], sub["name"][keep], sub.geometry[keep], table[keep].itertuples())
        ]
        features.sort(key=lambda f: (-f["properties"]["level"], -f["properties"]["risk"]))
        return {
            "type": "FeatureCollection",
            "computed_at": None if cd.computed_at is None else cd.computed_at.isoformat(),
            "stale": ctx.store.stale(cd),
            "truncated": len(features) > MAX_FEATURES,
            "features": features[:MAX_FEATURES],
        }
```

```tsx
  hour: number;

  refreshKey: number;
  onPick: (lat: number, lon: number) => void;

export function MapView({ city, hour, routes, refreshKey, onPick, onStatus }: Props) {
  const container = useRef<HTMLDivElement>(null);
  const map = useRef<MlMap | null>(null);

    const m = map.current;
    if (!m || !m.getSource("risk")) return;
    const bounds = m.getBounds();

      const data = await api.risk(

      // mất mạng: giữ lớp đang hiển thị
```

```python
from __future__ import annotations

import sqlite3
from contextlib import closing
from datetime import datetime, timezone
from pathlib import Path

from floodrisk.model.evidence import Report

SCHEMA = """
CREATE TABLE IF NOT EXISTS reports (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    city TEXT NOT NULL,
    unit_id TEXT NOT NULL,
    reporter TEXT NOT NULL,
    status TEXT NOT NULL,
    lat REAL NOT NULL,
    lon REAL NOT NULL,
    official INTEGER NOT NULL DEFAULT 0,
    created_at REAL NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_reports_city_time ON reports (city, created_at);
"""
REPLACE_WINDOW_S = 1800


class ReportDB:
    def __init__(self, path) -> None:
        self.path = str(path)
        Path(path).parent.mkdir(parents=True, exist_ok=True)
        with closing(self._connect()) as conn, conn:
            conn.executescript(SCHEMA)

    def _connect(self) -> sqlite3.Connection:
        return sqlite3.connect(self.path)

    def add(self, city: str, unit_id: str, reporter: str, status: str, lat: float, lon: float, now: float, official: bool = False) -> None:
        with closing(self._connect()) as conn, conn:
            conn.execute(
                "DELETE FROM reports WHERE city = ? AND unit_id = ? AND reporter = ? AND created_at >= ?",
                (city, unit_id, reporter, now - REPLACE_WINDOW_S),
            )
            conn.execute(
                "INSERT INTO reports (city, unit_id, reporter, status, lat, lon, official, created_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?)",
                (city, unit_id, reporter, status, lat, lon, int(official), now),
            )

    def active(self, city: str, now: float, max_age_s: float = 10800) -> dict[str, list[Report]]:
        with closing(self._connect()) as conn:
            rows = conn.execute(
                "SELECT unit_id, reporter, status, official, created_at FROM reports WHERE city = ? AND created_at >= ?",
                (city, now - max_age_s),
            ).fetchall()
        out: dict[str, list[Report]] = {}
        for unit_id, reporter, status, official, created_at in rows:
            at = datetime.fromtimestamp(created_at, tz=timezone.utc)
            out.setdefault(unit_id, []).append(Report(reporter, status, at, bool(official)))
        return out
```

```python
from typing import Literal

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

from floodrisk.api.context import Context

MAX_SNAP_M = 60.0


class ReportIn(BaseModel):
    city: str
    lat: float = Field(ge=-90, le=90)
    lon: float = Field(ge=-180, le=180)
    status: Literal["light", "medium", "high", "clear"]
    reporter: str = Field(min_length=8, max_length=64)


def register(app: FastAPI, ctx: Context) -> None:
    @app.post("/api/reports")
    def create_report(body: ReportIn):
        cd = ctx.city(body.city)
        pos = ctx.store.nearest(cd, body.lon, body.lat, MAX_SNAP_M)
        if pos is None:
            raise HTTPException(404, "Không có tuyến đường nào trong 60 m quanh vị trí này")
        unit_id = cd.units["unit_id"].iloc[pos]
        ctx.db.add(body.city, unit_id, body.reporter, body.status, body.lat, body.lon, time.time())
        row = ctx.view(cd, 0).loc[unit_id]
        return {
            "unit_id": unit_id, "name": cd.names[unit_id], "risk": round(float(row["risk"]), 3),
            "level": int(row["level"]), "reporters": int(row["reporters"]),
            "reported_level": None if row["reported_level"] is None else int(row["reported_level"]),
```

```python
from __future__ import annotations

import httpx

BASE = "https://rsapi.goong.io/v2"


class GoongError(Exception):
    pass


class Goong:
    def __init__(self, api_key: str, client: httpx.Client | None = None) -> None:
        self.api_key = api_key
        self.client = client or httpx.Client(timeout=15)

    def _get(self, path: str, params: dict) -> dict:
        try:
            res = self.client.get(f"{BASE}{path}", params={**params, "api_key": self.api_key})
        except httpx.HTTPError as exc:
            raise GoongError(f"không kết nối được ({exc})") from exc
        if res.status_code != 200:
            raise GoongError(f"HTTP {res.status_code}")
        return res.json()

    def autocomplete(self, q: str, lat: float | None = None, lon: float | None = None, limit: int = 6) -> list[dict]:
        params: dict = {"input": q, "limit": limit}
        if lat is not None and lon is not None:
            params["location"] = f"{lat},{lon}"
        out = []
        for p in self._get("/place/autocomplete", params).get("predictions") or []:
            fmt = p.get("structured_formatting") or {}
            out.append({
                "place_id": p["place_id"],
                "main": fmt.get("main_text") or p.get("description", ""),
                "secondary": fmt.get("secondary_text", ""),
            })
        return out

    def place(self, place_id: str) -> dict:
        result = self._get("/place/detail", {"place_id": place_id}).get("result") or {}
        location = (result.get("geometry") or {}).get("location")
        if not location:
            raise GoongError("không có tọa độ cho địa điểm này")
        return {"name": result.get("name", ""), "address": result.get("formatted_address", ""),
                "lat": location["lat"], "lon": location["lng"]}

    def directions(self, origin: tuple[float, float], destination: tuple[float, float], vehicle: str = "bike", alternatives: bool = True) -> list[dict]:
        data = self._get("/direction", {
            "origin": f"{origin[0]},{origin[1]}", "destination": f"{destination[0]},{destination[1]}",
            "vehicle": vehicle, "alternatives": "true" if alternatives else "false",
        })
        routes = []
        for route in data.get("routes") or []:
            legs = route.get("legs") or []
            polyline = route["overview_polyline"]
            routes.append({
                "distance_m": sum(leg["distance"]["value"] for leg in legs),
                "duration_s": sum(leg["duration"]["value"] for leg in legs),
                "polyline": polyline["points"] if isinstance(polyline, dict) else polyline,
            })
        return routes
```

```python
from __future__ import annotations

import pandas as pd
from shapely.geometry import LineString, Point

from floodrisk.api.store import CityData


def decode_polyline(text: str, precision: int = 5) -> list[tuple[float, float]]:
    coords, index, lat, lon, factor = [], 0, 0, 0, 10**precision
    while index < len(text):
        for is_lon in (False, True):
            shift = result = 0
            while True:
                byte = ord(text[index]) - 63
                index += 1
                result |= (byte & 0x1F) << shift
                shift += 5
                if byte < 0x20:
                    break
            delta = ~(result >> 1) if result & 1 else result >> 1
            if is_lon:
                lon += delta
            else:
                lat += delta
        coords.append((lon / factor, lat / factor))
    return coords


def _project(cd: CityData, coords: list[tuple[float, float]]) -> LineString:
    xs, ys = cd.to_proj.transform([c[0] for c in coords], [c[1] for c in coords])
    return LineString(list(zip(xs, ys)))


def score_route(cd: CityData, coords, risk_view: pd.DataFrame, buffer_m: float = 15.0, min_overlap_m: float = 50.0, min_frac: float = 0.3) -> dict:
    corridor = _project(cd, coords).buffer(buffer_m)
    units, exposure, flooded_m, max_level = [], 0.0, 0.0, 0
    for pos in cd.proj.sindex.query(corridor, predicate="intersects"):
        geom = cd.proj.iloc[pos]
        overlap = geom.intersection(corridor).length
        if overlap < min_overlap_m and overlap < min_frac * geom.length:
            continue
        unit_id = cd.units["unit_id"].iloc[pos]
        level, risk = int(risk_view.at[unit_id, "level"]), float(risk_view.at[unit_id, "risk"])
        exposure += overlap * risk
        max_level = max(max_level, level)
        if level == 2:
            flooded_m += overlap
        if level >= 1:
            units.append({"unit_id": unit_id, "name": cd.names[unit_id], "level": level, "overlap_m": round(overlap, 1), "pos": int(pos)})
    units.sort(key=lambda u: (-u["level"], -u["overlap_m"]))
    return {"exposure": round(exposure, 1), "flooded_m": round(flooded_m, 1), "max_level": max_level, "units": units}


def choose(routes: list[dict], max_ratio: float = 1.5) -> int:
    fastest = min(r["duration_s"] for r in routes)
    eligible = [i for i, r in enumerate(routes) if r["duration_s"] <= max_ratio * fastest]
    return min(eligible, key=lambda i: (routes[i]["flooded_m"], routes[i]["exposure"], routes[i]["duration_s"]))


def detour_points(cd: CityData, coords, risk_view: pd.DataFrame, offset_m: float = 600.0, snap_m: float = 400.0) -> list[tuple[float, float]]:
    scored = score_route(cd, coords, risk_view)
    worst = next((u for u in scored["units"] if u["level"] == 2), None)
    if worst is None:
        return []
    line = _project(cd, coords)
    middle = cd.proj.iloc[worst["pos"]].representative_point()
    along = line.project(middle)
    a, b = line.interpolate(max(along - 50.0, 0.0)), line.interpolate(min(along + 50.0, line.length))
    length = a.distance(b)
    if length == 0:
        return []
    nx, ny = -(b.y - a.y) / length, (b.x - a.x) / length
    levels = risk_view["level"]
    points = []
    for side in (1.0, -1.0):
        target = Point(middle.x + side * offset_m * nx, middle.y + side * offset_m * ny)
        near = cd.proj.sindex.query(target.buffer(snap_m), predicate="intersects")
        dry = [pos for pos in near if int(levels.at[cd.units["unit_id"].iloc[pos]]) == 0]
        if not dry:
            continue
        best = min(dry, key=lambda pos: cd.proj.iloc[pos].distance(target))
        snapped = cd.proj.iloc[best].interpolate(cd.proj.iloc[best].project(target)) if cd.proj.iloc[best].geom_type == "LineString" else cd.proj.iloc[best].representative_point()
        lon, lat = cd.to_wgs.transform(snapped.x, snapped.y)
        points.append((lat, lon))
    return points
```

```python
from __future__ import annotations

from typing import Literal

from fastapi import FastAPI, HTTPException

from floodrisk.api.context import Context
from floodrisk.api.goong import GoongError
from floodrisk.api.routing import choose, decode_polyline, detour_points, score_route
from floodrisk.config import CITIES


def _latlon(text: str, name: str) -> tuple[float, float]:
    try:
        lat, lon = (float(v) for v in text.split(","))
    except ValueError:
        raise HTTPException(422, f"{name} phải có dạng lat,lon")
    return lat, lon


def _check_inside(city: str, point: tuple[float, float], name: str) -> None:
    west, south, east, north = CITIES[city].bbox
    lat, lon = point
    if not (west <= lon <= east and south <= lat <= north):
        raise HTTPException(422, f"{name} nằm ngoài khu vực hỗ trợ của {CITIES[city].name}")


def _scored(cd, raw: dict, risk_view, via_detour: bool) -> dict:
    coords = raw["coords"] if "coords" in raw else decode_polyline(raw["polyline"])
    return {"distance_m": raw["distance_m"], "duration_s": raw["duration_s"], "coords": coords,
            "via_detour": via_detour, **score_route(cd, coords, risk_view)}


def _coords(raw: dict) -> list:
    return raw["coords"] if "coords" in raw else decode_polyline(raw["polyline"])


def register(app: FastAPI, ctx: Context) -> None:
    @app.get("/api/route")
    def route(city: str, origin: str, destination: str, vehicle: Literal["bike", "car"] = "bike"):
        cd = ctx.city(city)
        start, end = _latlon(origin, "origin"), _latlon(destination, "destination")
        _check_inside(city, start, "Điểm đi")
        _check_inside(city, end, "Điểm đến")
        if start == end:
            raise HTTPException(422, "Điểm đi và điểm đến trùng nhau")
        risk_view = ctx.view(cd, 0)
        try:
            found = ctx.goong.directions(start, end, vehicle, alternatives=True)
            if not found:
                raise HTTPException(404, "Goong không tìm được lộ trình nào giữa hai điểm này")
            routes = [_scored(cd, raw, risk_view, False) for raw in found]
            best = routes[choose(routes)]
            if best["flooded_m"] > 0:
                for waypoint in detour_points(cd, best["coords"], risk_view):
                    first = ctx.goong.directions(start, waypoint, vehicle, alternatives=False)
                    second = ctx.goong.directions(waypoint, end, vehicle, alternatives=False)
                    if first and second:
                        joined = {"distance_m": first[0]["distance_m"] + second[0]["distance_m"],
                                  "duration_s": first[0]["duration_s"] + second[0]["duration_s"],
                                  "coords": _coords(first[0]) + _coords(second[0])}
                        routes.append(_scored(cd, joined, risk_view, True))
        except GoongError as exc:
            raise HTTPException(502, f"Goong lỗi: {exc}")

        picked = choose(routes)
        fastest = min(range(len(routes)), key=lambda i: routes[i]["duration_s"])
        return {"routes": [
            {
                "id": i, "distance_m": r["distance_m"], "duration_s": r["duration_s"],
                "geometry": {"type": "LineString", "coordinates": [list(c) for c in r["coords"]]},
                "exposure": r["exposure"], "flooded_m": r["flooded_m"], "max_level": r["max_level"],
                "units": [{k: u[k] for k in ("unit_id", "name", "level", "overlap_m")} for u in r["units"]],
                "recommended": i == picked, "fastest": i == fastest, "via_detour": r["via_detour"],
            }
            for i, r in enumerate(routes)
        ]}
```

```python
from __future__ import annotations

from fastapi import FastAPI, Query

from floodrisk.api.context import Context

TOP_N = 5


def register(app: FastAPI, ctx: Context) -> None:
    @app.get("/api/alerts")
    def alerts(city: str, lat: float, lon: float, radius_m: float = Query(1500, gt=0, le=5000)):
        cd = ctx.city(city)
        unit_ids = cd.units["unit_id"].iloc[ctx.store.within(cd, lon, lat, radius_m)]
        hours = []
        for hour in (0, 1, 2):
            table = ctx.view(cd, hour).loc[unit_ids]
            risky = table[table["level"] >= 1].sort_values("risk", ascending=False).head(TOP_N)
            hours.append({
                "hour_offset": hour,
                "max_level": int(table["level"].max()) if len(table) else 0,
                "count_high": int((table["level"] == 2).sum()),
                "count_medium": int((table["level"] == 1).sum()),
                "top": [{"unit_id": unit_id, "name": cd.names[unit_id], "level": int(row["level"]), "risk": round(float(row["risk"]), 3)}
                        for unit_id, row in risky.iterrows()],
            })
        return {"hours": hours, "computed_at": None if cd.computed_at is None else cd.computed_at.isoformat()}
```

```python
from __future__ import annotations

import asyncio
import logging
from contextlib import asynccontextmanager

from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

from floodrisk.api import routes_alerts, routes_places, routes_reports, routes_risk, routes_route, settings
from floodrisk.api.context import Context
from floodrisk.api.goong import Goong
from floodrisk.api.reports import ReportDB
from floodrisk.api.store import Store

log = logging.getLogger("floodrisk.api")


def run_hourly() -> None:
    from floodrisk.jobs.hourly import run_all

    log.info("Tác vụ giờ xong cho: %s", run_all())


async def _refresh_loop(minutes: int) -> None:
    while True:
        try:
            await asyncio.to_thread(run_hourly)
        except Exception:
            log.exception("Tác vụ giờ lỗi; giữ nguyên lớp nguy cơ cũ")
        await asyncio.sleep(minutes * 60)


@asynccontextmanager
async def lifespan(app: FastAPI):
    minutes = settings.refresh_minutes()
    task = asyncio.create_task(_refresh_loop(minutes)) if minutes > 0 else None
    await asyncio.sleep(0)
    yield
    if task is not None:
        task.cancel()


def create_app() -> FastAPI:
    app = FastAPI(title="Lớp nguy cơ ngập đường", lifespan=lifespan)
    ctx = Context(store=Store(), db=ReportDB(settings.db_path()), goong=Goong(settings.goong_api_key()))
    app.state.ctx = ctx
    routes_risk.register(app, ctx)
    routes_reports.register(app, ctx)
    routes_places.register(app, ctx)
    routes_route.register(app, ctx)
    routes_alerts.register(app, ctx)
    dist = settings.web_dist()
    if dist.exists():
        app.mount("/", StaticFiles(directory=dist, html=True), name="web")
    return app


app = create_app()
```
